# 💡 Daavy's Lightswitch

A simple module for **Foundry VTT** that lets players turn map lights on and off by clicking interactive switch buttons on the screen.

---

## 🗂️ Features

- **🔘 Map Switches** — Adds a clickable light bulb icon right on top of map lights.
- **🔌 Player Controls** — Allows players to toggle lights even if they are not the Game Master (GM).
- **👁️ Smart Visibility** — Only shows light switches that players can see or have permission to use.
- **⚡ Instant Toggle** — Turns lights on or off instantly when clicked.

---

## ⚙️ Settings

- **Default Player Toggle** — Choose if newly created lights can be toggled by players by default.
- **Show for GM** — Choose if the Game Master (GM) sees the switch buttons on the map.
- **Debug Mode** — Turns on system logs and notifications to help with troubleshooting.
- **Reset Settings** — Resets all module settings back to default.

---

## 🛠️ Compatibility

- **Foundry VTT**: Version 14
- **Systems**: System-agnostic
